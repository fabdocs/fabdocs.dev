The goal: no human clicks "publish" in a production workspace. Changes land in
Git, CI validates them, and a pipeline promotes them dev → test → prod with
stage-specific parameters injected automatically.

- **dev** workspace is Git-connected. Engineers work in feature branches.
- **test** and **prod** receive changes only via the deployment pipeline.
- `parameter.yml` holds deployment rules; connection-level values move to
  [variable libraries](/docs/cicd/variable-libraries).
